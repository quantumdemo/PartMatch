# PartMatch Automated UI Snapshots

This directory contains automated PNG UI screenshots generated via Playwright.

## Folder Organization
- `/snapshots/mobile/`: Mobile responsive view screenshots (Viewport: 440px x 956px) for Customer (R-01/R-02), Seller (R-03), and Mobile Mechanic (R-04) roles.
- `/snapshots/admin/`: Desktop view screenshots (Viewport: 1440px x 900px) for Superadmin (R-05) roles.

## Regeneration Command
```bash
npm run snapshots
```
